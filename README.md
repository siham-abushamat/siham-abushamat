<h2>Projects</h2>

<h3>ESG Report Intelligence</h3>

A generative AI app that turns sustainability report PDFs into verified ESG data.
It extracts 17 standard ESG metrics from text, tables and charts, checks every number against the source PDF,
and shows the page each value came from.
